# Mango-Leaf-Classification-using-ML-Models

**_Deskripsi Proyek_**
Proyek ini membandingkan beberapa algoritma machine learning untuk mengklasifikasikan daun mangga berdasarkan **tinggi** dan **lebar daun**. Tujuannya adalah mengidentifikasi model dengan akurasi terbaik serta mengeksplorasi bagaimana fitur sederhana dapat digunakan untuk klasifikasi jenis daun.


**_Tujuan_**
- Mengimplementasikan dan membandingkan berbagai model ML: Decision Tree, KNN, Naive Bayes, dan SVM
- Melakukan analisis performa model berdasarkan akurasi, precision, recall, dan f1-score
- Menunjukkan kemampuan end-to-end data analysis untuk portofolio

Fitur Dataset
- `Tinggi`: Tinggi daun (cm)
- `Lebar`: Lebar daun (cm)
- `Kelas`: Label jenis daun mangga

**_Model yang Digunakan_**
- Decission Tree
- K-Nearest Neighbor
- Naive Bayes
- SVM
- Random Forest


**_Tools & Library_**
- Python (Google Colab)
- Pandas, NumPy
- Matplotlib, Seaborn
- Scikit-Learn
